# Типичные ошибки и сообщения

> **Контекст стенда** (нужен, чтобы команды ниже были корректны)
>
> Proxmox VE. Маршрутизаторы — **Eltex vESR 1.18**, остальное — **Альт Линукс**.
> Порты роутеров сдвинуты относительно топологии задания: **`gi1/0/2` — к ISP**, **`gi1/0/3` — внутрь офиса**
> (`net0`→`gi1/0/1` не используется, `net1`→`gi1/0/2`, `net2`→`gi1/0/3`).
> На vESR: применение — `do commit`, затем `do confirm`; на каждом интерфейсе и туннеле — `ip firewall disable`;
> удаление — повтор строки целиком с `no`. Просмотр: `show ip interfaces`, `show int status`, `show ip route`.
> В Альт: сеть в `/etc/net/ifaces/<iface>/`, применение `systemctl restart network`, пакеты через `apt-get`.
>
> Адресация: ISP `172.16.1.1/28` и `172.16.2.1/28` · HQ-RTR `172.16.1.2/28`, `192.100.100.1/25`, `192.100.200.1/26`, `192.100.30.1/29`
> · BR-RTR `172.16.2.2/28`, `192.100.20.1/28` · туннель `10.10.10.1/30` ↔ `10.10.10.2/30`
> · HQ-SRV `192.100.100.2` · HQ-CLI `192.100.200.2` · BR-SRV `192.100.20.2` · BR-CLI `192.100.20.3`
>
> Полный контекст — в [README](../README.md).

### Eltex vESR

| Сообщение                                                       | Что произошло                                                           | Что делать                                                      |
|-----------------------------------------------------------------|-------------------------------------------------------------------------|-----------------------------------------------------------------|
| `Syntax error: Illegal command line`                            | такой команды в этой прошивке нет                                       | набрать начало команды и `?`                                    |
| `Syntax error: Incompleted command`                             | не хватает аргумента                                                    | `no ip address 172.16.1.2/28`, а не просто `no ip address`      |
| `Syntax error: Unknown command` на `ping`                       | ты в режиме `(config)#`                                                 | `do ping 172.16.1.1` либо `exit`                                |
| `address belonging to subnet X is already present on interface Y` | одна подсеть живёт только на одном интерфейсе                           | снять адрес с интерфейса Y, потом ставить на нужный             |
| `in routing table already exists subnet 0.0.0.0/0`              | маршрут уже задан — это не ошибка                                       | проверить `show ip route`, при верном next-hop пропустить       |
| маршрут задан, но его нет в таблице                             | шлюз в сети, которой роутер не знает                                    | сначала поднять адрес на интерфейсе к этому шлюзу               |
| приглашение осталось `vesr(config)#`                            | ничего не применено                                                     | `do commit`, затем `do confirm`                                 |
| настроил, через 10 минут пропало                                | забыт `do confirm`                                                      | после каждого блока — `do commit` и `do confirm`                |
| адрес есть, но пинга нет                                        | не выключен межсетевой экран                                            | `ip firewall disable` на интерфейсе, либо настроить зоны        |

### Ответ ping как диагноз

| Ответ                               | Что значит                                            | Где искать                                    |
|-------------------------------------|-------------------------------------------------------|-----------------------------------------------|
| `connect: Network is unreachable`   | пакет даже не вышел, нет маршрута                     | свой конфиг: адрес не применился              |
| молчит, `100% packet loss`          | пакет ушёл, ответа нет                                | межсетевой экран или сосед                    |
| `Destination Host Unreachable`      | маршрут есть, MAC соседа не узнаётся                  | канальный уровень: мосты Proxmox, порт        |

### Альт Линукс

| Симптом                              | Причина                                                                  |
|--------------------------------------|--------------------------------------------------------------------------|
| `apt: command not found`             | в Альт команда называется `apt-get`                                      |
| `nano: command not found`            | редактор не установлен; используй `sed -i`, `vi` или поставь nano        |
| правлю файлы, ничего не меняется     | работает NetworkManager, либо правится не тот путь                        |
| `/etc/resolv.conf` не сохраняется    | он генерируется; править `/etc/net/ifaces/<if>/resolv.conf`              |
| `mkdir: File exists` на sysctl.conf  | это файл, а не папка                                                     |
| после перезагрузки массив `md127`    | описание не попало в `/etc/mdadm.conf`; в fstab ссылаться на UUID         |
| `exportfs: requires fsid=`           | экспортируется FAT32, нужен `fsid=1`                                     |
| NFS `Read-only file system`          | `ro` в exports, либо нет `umask=000` при монтировании массива            |
| `Clock skew too great`               | расхождение времени больше 5 минут                                       |
